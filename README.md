# RateLens 汇镜

一个面向日常换汇场景的汇率查询与提醒工具，支持电脑、iPhone、iPad 和 Android，安装到主屏幕后可像 App 一样使用。

## 在线使用

**[立即打开 RateLens 汇镜](https://ratelens.qqsqqs.workers.dev)**

无需下载安装，也无需注册账号。

## 主要功能

- 查询常用货币之间的参考汇率
- 查看中国银行现汇买入价和卖出价
- 以 1,000 外币为基准计算所需或可得人民币
- 查看不同时间范围的历史汇率走势
- 同时浏览多种常用货币
- 收藏常用货币对并记录换算
- 设置高于或低于目标值的汇率提醒
- 支持中文与英文、日间与夜间模式
- 支持 PWA 安装，可添加到手机或电脑主屏幕

## 安装到设备

### iPhone / iPad

1. 使用 Safari 打开在线地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 点击“添加”。

### Android

1. 使用 Chrome 打开在线地址。
2. 点击网页顶部的“安装”；或者打开右上角菜单。
3. 选择“安装应用”或“添加到主屏幕”。
4. 确认安装。

### Mac / Windows

使用 Chrome 或 Edge 打开网站，然后点击地址栏中的安装图标。Safari 用户也可以将网站添加到程序坞。

## 汇率说明

综合参考汇率用于查询和趋势参考；中国银行现汇模式会区分银行买入价与卖出价。实际成交价格可能受到更新时间、银行点差和渠道费用影响，请以交易机构最终报价为准。
